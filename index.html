Multiples of 3 or 5

This solution uses arithmetic-series sums and the inclusion-exclusion principle to avoid iteration. 


                function solution(number){
                    if(number < 0) return +0;
                    let dividedByThree = Math.floor((number - 1) / 3)
                    let dividedByFive = Math.floor((number - 1) / 5)
                    let commonNumOfNumbersDivisibleByBoth = Math.floor((number - 1) / 15)
                    return ((3 * dividedByThree * (dividedByThree + 1)) / 2) + ((5 * dividedByFive * (dividedByFive + 1) / 2)) - ((15 *  commonNumOfNumbersDivisibleByBoth * (commonNumOfNumbersDivisibleByBoth + 1)) / 2)
                }
